# Food image assets

Generated using the built-in imagegen tool for this module. These are AI-generated realistic illustrations, not photographs of weighed meals. The page labels them as illustrations and directs users to the written portion amounts.

Prompt set: three photorealistic Shanghai meal contact sheets, each with three columns (breakfast, lunch, dinner) and seven rows (Monday to Sunday). Natural daylight, white dishes, gray tabletop, complete single-person meals, no text or logos. Food subjects follow the home, office and noodle menus in ../data.js. Sheets were split into individual meal images and compressed for the website. File names identify plan, zero-based day and zero-based meal.

Original generated images are preserved in the Codex generated_images directory. All 63 site images are stored alongside this file. Changes to menu ingredients should be accompanied by an image review; the written portions, not pictured volume, are the reference.
